METHOD / CONTENT / EVIDENCE

Leer. Practicar. Documentar.

Un recorrido que no te pide confiar en cifras de progreso ficticias. Los documentos de cada semana son el centro de la experiencia.

01 / LECTURA

Comprende el problema.

El contenido completo de cada semana se presenta como HTML legible y preserva el archivo fuente.

02 / PRÁCTICA

Experimenta de forma ética.

Lee la sección de ejercicios existente. Nunca interpretes una lección como permiso para probar sistemas ajenos.

03 / EVIDENCIA

Construye tu criterio.

Marca objetivos y redacta tus resultados; exporta un archivo de texto de tus notas, sin almacenarlas en un servidor.

PROVENANCE / CONTINUITY

Ni páginas vacías ni certificados imaginarios.

Las 240 páginas HTML son tres vistas de 80 fuentes curriculares originales; la información se muestra al acceder a la web desde los archivos Markdown servidos por el mismo despliegue. Si falta una fuente, el lector lo indica.

La ampliación preserva el campus de React y su estructura. Su funcionamiento no prueba que el despliegue remoto esté listo: debe comprobarse el build en Vercel.

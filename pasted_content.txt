# 5. ⚠️ Regla importantísima

El agente IA **no debe poder hacer cualquier cosa**.

Por ejemplo:

```json
{
  "agent": "lab",
  "permissions": [
    "read_lab",
    "execute_lab",
    "read_terminal"
  ],
  "denied": [
    "modify_grades",
    "issue_credentials",
    "delete_student",
    "access_other_students"
  ]
}
```

Y todo queda registrado:

```text
AI_ACTION_LOG

agent
user
timestamp
tool
input
output
authorization
result
```

Esto es lo que convierte “IA” en **IA gobernada**.

# SECURE T — MASTER ENGINEERING DIRECTIVE

Transforma `belentani7/secure-t` desde su scaffold actual en una plataforma educativa de ciberseguridad e inteligencia artificial de nivel profesional.

NO construyas una simple landing page ni una demo de chatbot.

1. Open source first.
2. Prefer mature open-source projects over reinventing infrastructure.
3. Local/self-hostable whenever technically reasonable.
4. Standards-first architecture.
5. Security-by-design.
6. Privacy-by-design.
7. AI must be governed, auditable and permissioned.
8. Never give an AI agent unrestricted system privileges.
9. Separate academic authority from AI assistance.
10. Every important AI action must be auditable.

## CRITICAL

Do not fake functionality.

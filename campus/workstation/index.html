MANUAL / METODOLOGÍA

Este ordenador educativo complementa los cursos completos del campus.

01 / OBSERVAR

Identifica señales

Abre un caso, lee los registros y anota únicamente los hechos observables. Las IP usan rangos reservados para documentación, nunca objetivos reales.

02 / CONTRASTAR

No confundas indicio con prueba

Elige hipótesis, evalúa falsos positivos y declara qué otra evidencia necesitarías para confirmar o descartar un incidente.

03 / RESPONDER

Actúa con autorización

Prioriza preservación de evidencias, proporcionalidad, privacidad y escalado. No realices pruebas fuera de un entorno autorizado.

04 / JUSTIFICAR

Documenta tu criterio

Escribe una cronología, recomienda el siguiente paso y exporta tu cuaderno para revisión humana. Completar un reto no es una certificación.

# Secure T: biblioteca de cursos íntegros

Conecta los cuatro programas de veinte semanas con sus fuentes reales en `campus/cursos/`. Reutiliza lecciones y preguntas ya existentes. No reemplaza la academia ni sus laboratorios, ni declara certificación oficial. El progreso es local al navegador.

El catálogo ofrece enlaces HTML directos a los cuatro cursos si JavaScript está desactivado. Cada página de semana corresponde a un archivo Markdown original; las semanas sin contenido no se publican.
